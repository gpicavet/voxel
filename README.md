Simple voxel engine using WebGL.

Using Ray-traced shadows.

Controls: arrows to move and turn, `z` / `s` to look up and down, `space` to blow up the terrain, `p` to toggle the depth pre-pass.
The overlay shows fps, GPU time (when `EXT_disjoint_timer_query_webgl2` is available), visible chunks and triangles drawn.
